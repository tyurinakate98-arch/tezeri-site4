# ТЕЗЕРИ — быстрая загрузка через браузер GitHub

В этой папке 96 файлов. Это готовый сайт для просмотра: все 17 страниц,
три опубликованные статьи, изображения, видео, шрифты и анимации сохранены.
Внешний вид и работа опубликованных страниц совпадают с полной версией.

## Загрузить

1. Распакуйте ZIP в отдельную папку.
2. В репозитории GitHub откройте Add file → Upload files.
3. Перетащите всё СОДЕРЖИМОЕ распакованной папки: index.html, остальные
   файлы и папку assets. Не перетаскивайте ZIP или внешнюю папку целиком.
   Файл index.html должен оказаться в корне репозитория.
4. Нажмите Commit changes и сохраните файлы в основную ветку (обычно main).
5. Откройте Settings → Pages. Source: Deploy from a branch.
   Branch: main (или ваша основная ветка), папка: /(root). Нажмите Save.
6. Дождитесь успешного размещения; ссылка появится в Settings → Pages.

Для этого облегчённого архива выберите Deploy from a branch, даже если
раньше для полного пакета выбирали GitHub Actions.

Если в репозитории уже есть старый пользовательский workflow
Publish TEZERI preview, временно отключите именно его через Actions →
выбрать workflow → меню … → Disable workflow, чтобы он не публиковал
старые исходники поверх новой готовой версии. Это не касается штатной
сборки Pages build and deployment, создаваемой GitHub.

## Что сохранить для дальнейшей работы

Полный архив TEZERI-GitHub-2026-10-16.zip содержит исходники, редактор
статей, сборщик и workflow. Сохраните его отдельно. Здесь уже находятся
все опубликованные статьи, но автоматическое создание новых страниц
из Markdown требует полного архива и его workflow.

В этой версии индексация остаётся выключенной (noindex), как и в макете.
Регистрация и чат пока не подключены. Для знакомства с сайтом это не мешает.
